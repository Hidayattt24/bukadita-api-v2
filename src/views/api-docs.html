📋 Overview

Base URL: http://localhost:8080

API Prefix: /api/v1

Version: 1.0.0

Total Endpoints: 119

Response Format

Semua response menggunakan format standar:

Success Response:

{ "error": false, "code": "SUCCESS_CODE", "message": "Success message", "data": {} }

Error Response:

{ "error": true, "code": "ERROR_CODE", "message": "Error message" }

HTTP Status Codes

Code Status Description
200 OK Request berhasil
201 Created Resource berhasil dibuat
400 Bad Request Validation error
401 Unauthorized Token tidak valid atau expired
403 Forbidden Tidak memiliki permission
404 Not Found Resource tidak ditemukan
500 Internal Server Error Error server

User Roles

Role Description Capabilities
USER User biasa (Kader) View modules, take quizzes, track progress
ADMIN Administrator Manage content, view all user progress
SUPER_ADMIN Super Administrator Full access + user management

🔐 Authentication

Authentication Method: JWT Bearer Token

Header Format: Authorization: Bearer <token>

Token Expiry: Access Token (24h), Refresh Token (7d)

POST /auth/register Public
Register user baru dengan role USER
// Request Body { "email": "user@example.com", "password": "password123", "name": "Nama User", "phone": "081234567890" }
POST /auth/login Public
Login untuk user biasa
// Request Body { "email": "user@example.com", "password": "password123" } // Response { "error": false, "code": "LOGIN_SUCCESS", "data": { "user": { "id": "uuid", "email": "...", "role": "USER" }, "tokens": { "accessToken": "jwt_token", "refreshToken": "refresh_token" } } }
POST /auth/admin-login Public
Login khusus untuk admin/super admin
POST /auth/refresh Public
Refresh access token menggunakan refresh token
// Request Body { "refreshToken": "refresh_token_here" }
POST /auth/logout Protected
Logout user dan invalidate token
POST /auth/profile Protected
Create atau update profile user
POST /auth/request-password-reset Public
Request OTP untuk reset password
// Request Body { "phone": "081234567890" }
POST /auth/verify-otp-reset-password Public
Verifikasi OTP dan reset password
// Request Body { "phone": "081234567890", "otp": "123456", "newPassword": "newPassword123" }

📚 Modules

GET /modules Public
Mendapatkan semua modul yang tersedia

Query Parameters: page, limit

GET /modules/:slug Public
Mendapatkan detail modul berdasarkan slug
POST /modules Admin
Membuat modul baru
// Request Body { "title": "Modul Baru", "slug": "modul-baru", "description": "Deskripsi modul", "order": 1, "isPublished": true }
PUT /modules/:id Admin
Update modul yang ada
DELETE /modules/:id Admin
Hapus modul

📖 Materials

GET /materials Admin
Get semua materi (termasuk unpublished)

Query Parameters: moduleId, page, limit

GET /materials/public Public
Get materi yang published saja

Query Parameters: moduleId (required)

GET /materials/:id/public Public
Get detail materi beserta sub materi dan poin detail
GET /materials/:id/quiz Public
Get quiz yang terkait dengan materi
GET /materials/:id/points Protected
Get poin details untuk materi tertentu
POST /materials Admin
Membuat materi baru
// Request Body { "moduleId": "module_uuid", "title": "Materi Baru", "slug": "materi-baru", "description": "Deskripsi materi", "order": 1, "isPublished": true }
POST /materials/points Admin
Membuat poin detail baru
POST /materials/points/:id/media Admin
Upload media (gambar/video) ke poin detail

Content-Type: multipart/form-data

Max Size: 10MB

📝 Quizzes

GET /quizzes/module/:moduleId Public
Get semua quiz untuk modul tertentu
GET /quizzes/:id Public

POST /quizzes/submit Protected

// Request Body { "attemptId": "attempt_uuid", "answers": [ { "questionId": "question_uuid", "selectedOption": "opt1" } ] }
GET /quizzes/attempts/me Protected

GET /quizzes/attempts/my Protected
Get riwayat quiz attempts user per modul
